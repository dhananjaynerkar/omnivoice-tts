Desktop Companion (Windows)

Bridge text-to-speech beyond Chrome into VS Code, Notepad, Microsoft Word, and terminal windows.

Connects to local companion service on 127.0.0.1:8765.

How to Run the Desktop Companion

  1. Open terminal in desktop-companion and activate virtual environment: .\.venv\Scripts\activate
  2. Run python main.py (or simply double-click run.bat)
  3. Copy the generated Security Token and paste it into the field above
  4. Select text in VS Code or any desktop window and press Ctrl+Alt+R

Privacy & Security Architecture

Clear disclosure on data flow, zero-telemetry policy, and local isolation guarantees.

Data Flow Guarantee

  • Default Offline Mode: When using the Browser Native TTS provider, 100% of text processing and speech synthesis occurs completely on your device. Zero bytes leave your machine.
  • AI Provider Isolation: Text is ONLY sent to Google AI Studio if you explicitly choose the Google AI provider or enable AI features.
  • Untrusted Data Defense: Webpage text is encapsulated in strict boundaries to neutralize prompt injection attacks.
  • Zero Telemetry: We collect zero analytics, tracking cookies, or usage statistics. Telemetry is permanently disabled.
